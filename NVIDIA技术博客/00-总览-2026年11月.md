## 这批文章在讲什么

11 月的 NVIDIA 博客有一条明显的重心：**agent 不再是模型的事，是基础设施的事。**
四篇正文两两成对：

| 对 | 一篇讲「agent 跑在哪」 | 一篇讲「agent 会不会越界」 |
|---|---|---|
| 执行侧 | Agent Substrate：把闲置的 agent 沙箱快照出去，塞进共享 worker 池 | Sentry：在 DPU 上、agent 够不到的地方盯它 |
| 模型侧 | Nemotron 3.5 Super VL：一个模型同时看图和读文档 | GLM-5.3 双机：单卡装不下的模型怎么拆 |

对老大有用的是前一对的概念，不是后一对的硬件。

## 只看过摘要的（按时间倒序）

**11-13**
- **Faster Scientific Simulations with New FP64 Algorithms in NVIDIA cuBLAS**：高精度（双精度）稠密线性代数的新算法，针对分子化学、材料科学的仿真。摘要级。
- **Run GPU-Powered Black Hole Interferometry with NVIDIA cuPhoton**：用 GPU 做黑洞干涉成像。文中举的例子是 M87* 的观测环在天空中只占 42 微角秒（一角秒的百万分之四十二）。摘要级。
- **Run Native DLA Inference in Python on NVIDIA Jetson AGX Orin Using cuDLA**：在边缘设备上用 Python 直接调 DLA（Deep Learning Accelerator，Jetson 上的专用推理单元），解决「多个网络挤在有限算力和功耗里」的问题。摘要级。

**11-11 / 11-10**
- **Validating GPU Platforms with Runtime AI Inventory via the NVIDIA DSX AI Factory**：确认集群上「实际在跑什么」，而不只看部署声明。摘要级。
- **Running AV Reasoning Models Within Onboard Compute and Latency Limits**：车载推理模型的算力和延迟约束。摘要级。
- **Agent Substrate**：见分篇。

**10-27 及更早**
- **3 Ways to Boost MoE Inference on NVIDIA DGX Spark**：在 batch size = 1 的条件下给 Ling-3.0-flash 找瓶颈。这篇对「怎么定位推理慢在哪」有方法论价值，值得单独读。摘要级。
- **ReplaySSM**：混合模型（状态空间层 + 少量注意力层）的状态存储该放哪。涉及 Nemotron 3、Qwen 3.5~3.8、Kimi-K3、GLM-5.3-Flash 这类混合架构。摘要级。
- **AIPerf**：LLM 推理压测工具，GLM-5.3 那篇的吞吐数字就是它跑出来的。摘要级。
- **TensorRT 多设备 + Dynamo-Triton**、**Groq 3 LPX 确定性执行**、**NIM 全栈优化 2.5x 用户**、**投机解码 co-design**、**GPU 选型与 TCO**：都是「怎么把推理跑得更省」的不同切面。摘要级。

## 一句话判断

这四篇正文里，**只有 Agent Substrate 和 Sentry 的思路能直接搬到单机上**。
另外两篇的前提是「你有一张 GB300」和「你要后训练一个 120B 模型」，本机都没有。
读它们是为了理解概念，不是为了照做。哪个是哪个，分篇里都写清了。
